# Follow-up and metrics

## What actually counts

Priority measures, in order:

1. Repeat attendance
2. Meaningful group participation
3. Member referrals
4. Conversations that continue between events
5. Collaborations that start here
6. Newcomers being included
7. Organizer enjoyment

Secondary, and never optimised for: raw group size, follower counts,
impressions, free-event registrations, and one unusually large event.

## Six-month dashboard

`templates/six-month-dashboard.csv`

    month,events_held,unique_attendees,repeat_attendees,repeat_rate,online_members,active_contributors,member_referrals,moderation_incidents,spend_inr,venue_partners,organizers_capable_of_hosting,organizer_enjoyment_1_to_5,notes

`repeat_rate` = repeat attendees ÷ attendees who were eligible to return (that
is, people who had already attended at least one earlier event). Record zero
honestly. A dashboard that flatters the organizer is worthless.

## Six-month targets

Diagnostic, not incentives. Do not compromise the culture to hit a number.

| Target | Value |
| --- | --- |
| Core regulars | 8–15 |
| Online members | 100–250 |
| Typical event attendance | 15–30 |
| Completed events | 12 |
| Other people able to run an event | 2 |
| Dependable venue or community partners | 1–2 |
| Repeat attendance rate | at least 40% |

## Monthly cycle

1. One tech hangout.
2. One build-together session.
3. One public recap per event.
4. One personal confirmation before each event.
5. One next-day follow-up after each event.
6. Dashboard updated.
7. Thirty-minute organizer retrospective.

## Weekly workload ceiling

Roughly five hours outside event time. If it goes above this consistently, cut
scope rather than burning out.

| Activity | Time |
| --- | --- |
| Outreach and follow-ups | 60–90 min |
| WhatsApp participation and moderation | 45–60 min |
| Venue and event coordination | 60 min |
| One public update or event post | 30–45 min |
| Registrations, attendance, interests | 30 min |
| Unexpected | remainder |

Protect the two recurring formats first. Everything else is optional.

## Adding helpers

Invite a conversational host, build facilitator, photographer, or moderator only
after someone attends consistently, follows the conduct rules, and helps without
chasing status.

No committees, no elections, no membership tiers, no oversized core team.
Responsibility follows demonstrated behaviour.
